# The Diet App

Приложение для расчёта питания (КБЖУ) и диет для разных групп здоровья.
Реализованы: модуль нормы калорий и БЖУ (с учётом заболеваний и стадий жизни) и
локальная база продуктов из двух источников (USDA + Open Food Facts).

## Структура

```
The_Diet_app/
├── diet/                  # пакет с логикой расчёта КБЖУ
│   ├── profile.py         #   данные человека + справочники (активность, цель)
│   ├── conditions.py      #   нозологические группы (диабет, ХБП, ожирение, ССЗ)
│   ├── life_stages.py     #   стадии жизни (спортсмен, пожилой, беременность...)
│   └── calculator.py      #   BMR, TDEE, целевые ккал, БЖУ
├── scripts/               # пайплайн подготовки базы продуктов
│   ├── 01_prepare_usda.py #   распаковка USDA + нормализованная таблица
│   ├── 02_download_off.py #   скачивание дампа Open Food Facts (~12 ГБ)
│   └── 03_filter_off_ru.py#   фильтрация российских продуктов из дампа
├── notebooks/
│   ├── 01_kbzhu.ipynb     # расчёт нормы калорий и БЖУ
│   └── 02_products_explore.ipynb  # обзор базы продуктов
├── data/
│   ├── downloads/         # исходные архивы (USDA zip, OFF dump ~74 ГБ)
│   ├── foundation_foods/  # распакованный USDA
│   └── processed/         # ← готовые таблицы:
│       ├── usda_foods.csv #   469 базовых продуктов (КБЖУ + микроэлементы)
│       └── off_ru_foods.csv #  российские брендированные продукты из OFF
├── .venv/
└── requirements.txt
```

## База продуктов

Две таблицы в `data/processed/`, дополняющие друг друга:

| Файл | Источник | Что содержит |
|---|---|---|
| `usda_foods.csv` | USDA Foundation Foods | 469 базовых продуктов (яблоко, мясо, крупы) — полный нутриентный анализ |
| `off_ru_foods.csv` | Open Food Facts (Россия) | российские брендированные продукты (йогурты, хлеб, сыры) |

Схема колонок одинаковая: `kcal, protein_g, fat_g, carbs_g, fiber_g, sugars_g, sat_fat_g, sodium_mg, potassium_mg, calcium_mg, iron_mg, vitc_mg`.

Пересборка базы (из `scripts/`):
```bash
./.venv/Scripts/python.exe 01_prepare_usda.py     # ~10 сек
./.venv/Scripts/python.exe 02_download_off.py     # ~40 мин (скачивание + распаковка)
./.venv/Scripts/python.exe 03_filter_off_ru.py    # ~30 мин (фильтрация 74 ГБ дампа)
```

> Дамп OFF (~74 ГБ распакованный) нужен только для пересборки РФ-таблицы.
> Готовые таблицы в `data/processed/` — компактные, можно работать без дампа.

## Установка (один раз)

Окружение `.venv` уже создано (Python 3.11.9). Если нужно пересоздать:

```bash
# Git Bash, из папки проекта
python -m venv .venv
./.venv/Scripts/python.exe -m pip install --upgrade pip
./.venv/Scripts/python.exe -m pip install -r requirements.txt
./.venv/Scripts/python.exe -m ipykernel install --name diet --display-name "Python (diet)" --sys-prefix
```

## Запуск

```bash
./.venv/Scripts/jupyter-lab.exe
```

Откроется браузер → открой `notebooks/01_kbzhu.ipynb`. Убедись, что ядро справа
вверху — **Python (diet)**. Заполни ячейку «Данные человека» и выполни все ячейки
(`Shift+Enter`).

## Что считает модуль КБЖУ

- **BMR** (базовый обмен) — две формулы на выбор, обе выводятся в таблице сравнения:
  - `who` — уравнения Скофилда, официальный стандарт ФАО/ВОЗ/ООН (4 возрастные группы);
  - `mifflin` — формула Миффлина–Сан Жеора (современная, часто точнее).
- **TDEE** — расход за день = BMR × коэффициент активности.
- **Целевые ккал** — TDEE с поправкой на цель (−500 / 0 / +300), не ниже
  безопасного минимума (жен. 1200 / муж. 1500 ккал).
- **БЖУ** — зависит от нозологической группы (`condition`) и стадии жизни (`life_stage`).

Параметры: `formula`, `condition`, `life_stage`. При конфликте белка между болезнью
и стадией жизни приоритет у ХБП (защита почек); рискованные комбинации отмечаются
в `result.warnings`.

### Нозологические группы (`condition`)

Белок может задаваться долей энергии (%) или граммами на кг веса (г/кг).
Жиры ≤30%, углеводы — остаток от калорий.

| Ключ | Группа | Белок | Источник |
|---|---|---|---|
| `healthy` | Здоровый взрослый | 15% | ВОЗ 2023 |
| `diabetes_t2` | Сахарный диабет 2 типа | 18% (15–20%) | ADA / Diabetes Canada |
| `obesity` | Ожирение / снижение веса | **1,3 г/кг** | Obesity Society (1,2–1,6 г/кг) |
| `ckd` | ХБП, стадии 3–5 (без диализа) | **0,8 г/кг** | KDIGO 2024 / KDOQI 2020 |
| `cvd` | ССЗ / гипертония | 15% (жиры ≤30%) | AHA |

### Стадии жизни (`life_stage`)

Ортогональны болезням — описывают здорового человека с особыми потребностями.

| Ключ | Стадия | Белок | Калории | Источник |
|---|---|---|---|---|
| `default` | Обычный взрослый | (по condition) | (по цели) | — |
| `athlete_endurance` | Спортсмен на выносливость | **1,3 г/кг** | — | ISSN (1,0–1,6) |
| `athlete_strength` | Спортсмен-силовик / набор | **1,8 г/кг** | — | ISSN (1,6–2,0) |
| `older_adult` | Пожилой (60+) | **1,1 г/кг** | — | PROT-AGE (1,0–1,2) |
| `pregnant` | Беременность (2–3 триместр) | **+25 г** | **+340 ккал** | NAM / RDA |
| `lactating` | Кормление грудью | **+25 г** | **+500 ккал** | NAM / RDA |

> ⚠️ Расчёт ориентировочный, не заменяет консультацию врача/диетолога.
> Качественные ограничения (натрий, насыщенные жиры, пурины) заработают
> по-настоящему после подключения базы продуктов — пока только текстовые
> рекомендации в `result.notes`.
